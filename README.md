# Amazon Prime Power BI Project

## Project Overview
This project analyzes the Amazon Prime Movies dataset using Python and Power BI.

## Objectives
- Clean the dataset
- Handle missing values and duplicate records
- Perform Exploratory Data Analysis (EDA)
- Analyze release year, genres, age certification, production countries, IMDb scores, and runtime
- Build an interactive Power BI dashboard

## Tools Used
- Python
- Google Colab
- Pandas
- Matplotlib
- Power BI

## Conclusion
This project provides valuable insights into Amazon Prime movie data through interactive dashboards and visualizations.
